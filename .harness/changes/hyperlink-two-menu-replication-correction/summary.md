## 关键设计决策

- 不再把“一期范围”当作“完整复刻”的验收口径。
- 点击与趋势依赖尚未存在的超链任务事实，禁止造假；已补完整导出合同和详细右抽屉，事实源未就绪时明确展示真实空态。
- 模板页实际锁定单个 URL 按钮，沿用现有 JSON 与校验，不误扩通用组件能力。
- 敏感号码导出使用独立权限，不复用普通查看权限。
- 主国家取当前代号码量最多的国家；并列时优先已识别国家，再按 ISO2 排序。空包不属于 UNKNOWN。
- 马来西亚、新加坡、中国、香港、澳门、台湾号码在后端整批拒绝，失败导入只保留审计、不写号码行。

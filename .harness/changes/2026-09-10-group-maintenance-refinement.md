# 养群管理三菜单与逐群资格

- 日期 / 分支 / 工作目录：2026-09-10 / 1.0.3-snapshot / Armada 主工作目录。
- 状态：本地实现与聚焦验证完成；未提交、推送、部署、访问真库或启动真实任务。
- 需求来源：用户确认分组随机安排推手、全部勾选群营销、提交时刻计时；推手不足交给独立进群任务处理，并展示友好缺口。

## 实施

具体契约见 [业务说明](../../docs/business/2026-09-10-group-maintenance-requirements.md)。

- 三菜单已形成素材、可复用剧本、任务实例的流程。素材复用 marketing_template / marketing_template_file，定义软删除不影响任务快照。
- 角色由业务人员配置；管理员手工选择，推手逐群无放回随机绑定；总池严格大于角色数，单群实际可用人数至少达到角色数。
- 分组群搜索、完整缺口报告、保存草稿后去进群任务、重新检查和启动拦截均已接入。任一目标不达标，首次发送前整个任务零提交。
- 新任务按前项提交时刻调度下一项，回执独立收敛；任务/单群暂停恢复保留原身份、原命令，不保留下一项剩余等待。
- 新增 V185 / V186，旧固定账号任务保持原执行语义。新增字段、聚合理由、权限、异常默认行为见业务说明。
- 未扩展进群执行、协议引用回复、每日重复或可配置跳过策略。未添加素材删除入口。

## 当前决策

- 独立菜单和列表页，新建/编辑及详情使用新抽屉；不在旧页面添加模式或修改旧表单。
- 新前端目录与 API client、新 /api/script-marketing-tasks 接口及独立任务数据；旧营销创建接口和任务表不因本功能调整。
- 单项成功或失败后均继续下一项，失败不补发、不自动换号。
- 发送超时仍无结果时记录未知并继续；不能误记为确定未发送，也不能盲目重发。
- 暂停恢复沿用进度和原命令，不重发已成功、已失败或已超时结束的项。
- 最后一项失败也结束列表，完成状态与成功/失败/未知数量分开显示。
- 任务设置统一间隔，新表单与控制独立；仅使用基础 UI、账号/素材及通用发送能力，模板读取后复制到新任务，不回写旧模板。
- 只保留新任务配置及发送项、每群进度和发送结果三类必要事实；不新增独立剧本库、发布流程、通用工作流、自动重试或跨业务调度系统。
- 重复回调和原命令跟踪是暂停恢复不重复发的必要保护，协议层是否真正去重需验收。

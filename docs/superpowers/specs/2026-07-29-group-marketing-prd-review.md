# 拉群营销 PRD V1.2——第 8 章评审记录

## 结论

第 8 章看完后，页面的大体结构已经能确定，但还不能直接进入完整开发。

当前可以先确定为 **6 步式新建任务页面**。仍需补齐的核心问题是：目标数据分配公式、字段联动、最低成功标准、强制营销门槛和提交前资源预检。

## 推荐页面结构

| 步骤 | 页面 | 主要内容 |
| --- | --- | --- |
| 1 | 基础信息与选群 | 任务名称、群来源筛选、目标群组选择、已选群汇总 |
| 2 | 群组处理 | 清理成员、修改群名称/头像/描述、配置群权限 |
| 3 | 账号资源 | 接管管理员、营销账号、拉手、水军的分组与分配 |
| 4 | 水军、目标数据与最低标准 | 水军数量、目标数据、分配策略、最低成功标准、未达标策略 |
| 5 | 营销规则 | 模板、发送轮次或时长、发送间隔、开始方式、强制营销 |
| 6 | 资源预检与提交 | 容量、账号冲突、额度、号码预占、最终预览和二次确认 |

页面右侧或顶部建议固定显示：

- 已选群数量。
- 各角色账号可用数量。
- 计划水军数、目标数和候选数。
- 群容量风险和当前阻断项。

## 需要修正的关键问题

### 1. 目标数据分配公式不成立

原文使用“目标总数 ÷ 群数”计算每群目标数，只能得到平均计划数，不能作为实际分配量。

实际分配时还必须考虑：

- 群当前保留成员数。
- 接管管理员、营销账号、拉手和水军占用的人数。
- 群安全余量。
- 拉手剩余额度。
- 清洗后的可用目标号码。
- 为失败、隐私和未注册准备的候选补偿量。

建议拆成四个概念：

| 概念 | 含义 |
| --- | --- |
| 计划目标成功数 | 业务希望每群最终新增或达成的人数 |
| 候选尝试上限 | 为覆盖失败、隐私、未注册等结果准备的最大候选量 |
| 群剩余安全容量 | 群容量上限扣除保留成员、平台账号、水军和安全余量 |
| 本次实际分配量 | 当前所有约束下，真正预占给该群的号码数 |

推荐公式：

```text
本次实际分配量 = min(
  剩余候选计划,
  清洗后可用号码,
  拉手剩余额度,
  群剩余安全容量
)
```

### 2. 群来源不应由用户重复填写

历史老群、自收群应该是群组自身属性。

创建任务时，用户只负责筛选和选择群组；任务来源由所选群自动派生。若同时选择两类群，任务可以显示为 `MIXED`。

### 3. 账号资源之间需要明确互斥

接管管理员、营销账号、拉手、水军不能只选择账号分组，还要在提交前校验：

- 同一账号是否被分配到多个角色。
- 接管管理员是否能覆盖全部目标群。
- 账号是否在线、健康、未被其他任务占用。
- 拉手、水军是否还有当日和单任务额度。
- 营销账号在禁言群中如何获得发言权限。

### 4. 最低成功标准缺少完整失败分支

最低成功标准可以支持固定人数或比例二选一，但必须明确比例的分母。

未达标后不能只停在“失败”，需要配置最终处理策略：

1. 补充拉手继续执行。
2. 跳过当前群营销。
3. 触发强制营销。
4. 转人工处理。

### 5. 强制营销不能绕过安全条件

强制营销建议只允许绕过“最低拉人成绩”，不能绕过以下条件：

- 营销账号已经进群。
- 营销账号具备发言权限。
- 营销模板快照有效。
- 群组没有被停止或进入不可执行状态。

强制营销开始后，剩余拉人流程继续执行，不能自动停止拉手或取消目标数据。

### 6. 营销开始方式需要明确时间语义

建议支持：

- 立即开始。
- 延迟指定时长。
- 在统一时刻开始。

选择统一时刻时，页面必须明确展示任务时区。营销执行模式建议使用“固定轮次”和“固定时长”二选一。

### 7. 草稿是否占用资源需要明确

建议保存草稿时不占用群组、账号和目标号码。

进入最终提交预检时再做短时锁定，并设置 TTL；预检失败、用户退出或超时后自动释放。

### 8. 提交前必须增加统一资源预检

最终提交前至少检查：

- 群仍可执行，原管理账号仍有权限，群数据没有过期。
- 接管管理员、营销账号、拉手和水军数量充足且没有角色冲突。
- 群容量可以容纳平台账号、水军和目标计划。
- 目标号码已完成格式校验、去重、已使用校验和预占校验。
- 模板、开始时间、时区和强制营销配置有效。

预检失败时，需要按群或资源展示原因，并能跳回对应步骤修改。

## 第 8 章还缺的前端规格

- 字段、类型、默认值、必填条件、显示条件和禁用条件矩阵。
- 6 个步骤的低保真原型或页面线框图。
- 提交预检错误码与页面定位规则。
- 草稿保存、返回编辑、数据过期和资源冲突的交互说明。
- 强制营销、查看完整号码等敏感操作的权限规则。

## 需要确认的决定

1. 页面是否采用“6 步向导 + 固定资源摘要”。
2. 是否允许同一任务混选历史老群和自收群。
3. 草稿是否不占用资源，只在最终预检阶段短时锁定。
4. 最低成功标准采用固定人数还是比例，比例分母是什么。
5. 未达标后的默认处理顺序是什么。
6. 强制营销是否只允许绕过最低拉人成绩。
7. 营销执行采用固定轮次还是固定时长。
8. 统一开始时刻使用哪个任务时区。

## 关键设计决策

- 待审核当前直接记失败；新增分支应在终态失败之前接入，处理期间保持 PENDING。
- 不提前检测审核；群 JID 缺失时只在待审核分支解析。
- 复用 GroupSettingsPort 与原群管理员候选；不能把“关闭成功”直接当“入群成功”。
- 建议关闭后检查当前目标成员/申请事实，必要时批准指定申请或一次受控续进群；具体真实协议行为尚未实群验证。
- 优先复用 HTTP 设置接口，避免强行复用只接受拉群关联的 Kafka 群设置命令；如使用 Kafka 必须完整扩展独立契约。
- 本次不动历史失败行，不操作真实群，不覆盖其他会话修改。

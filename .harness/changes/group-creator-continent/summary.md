# 群创建者国家与洲展示修正

## 目标

- 兼容 WhatsApp 历史墨西哥移动号码 `521 + 10位国内号`。
- 群列表不再根据手机号推断州/省，只展示创建者国家对应的洲。
- 国家主数据补齐 `ANTARCTICA`，使七大洲代码与列表筛选白名单一致。

## 实现

- 号码先按 libphonenumber 严格校验；仅当原号码无效且符合墨西哥历史格式时，规范为 `52 + 10位国内号` 后重试。
- 群快照只调用国家解析，不再查询手机号州号段或离线 geocoder。
- 群列表对当前页中“国家为空、创建者号码存在”的历史快照做一次批量解析，只补齐本次响应，不写库且不覆盖已有国家快照。
- 运行时移除州推断接口、模型、Mapper 和群列表州字段；已执行的 V129 历史迁移保持不变。
- V131 将 `AQ/BV/HM/TF` 的 `continent_code` 更新为 `ANTARCTICA`。

## 验证

- 国家解析：墨西哥历史/当前格式（含现场号码 `5217541087825`）及阿根廷、巴西标准 WhatsApp 格式。
- 群快照：仅写入国家与洲。
- 群列表：页面显示“洲”，七大洲字典包含南极洲；历史墨西哥快照可在读取时补出墨西哥和北美洲。

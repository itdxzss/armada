# 终态未提交建群账号预留释放

主记录：[方案、进度与验证](../2026-10-08-creator-reservation-release.md)。

- 账号生命周期聚合增加释放历史表 V217；保留原冻结快照与原因，主表安全删除以空出账号及全局身份唯一键。历史与当前保护不是重复事实。
- 任务账本新增 RELEASED(6)，仅终态执行、未提交、无同执行在途命令可释放；角色只收口原任务执行的 role4，账号状态不动。
- API `/api/accounts/batch-takeover` 复用 `AccountBatchCommandResultVO`，返回 `failed/batchErrors`，生命周期拒绝按账号隔离重试。
- 前端进度增加“预留已释放（未注销）”，抢登使用现有部分受理反馈。
- Redis 无变更；协议层无变更。回滚只回退应用，保留历史与安全释放结果。
- 用户明确指定在主仓叠加其他会话在途改动。部署需另行确认 perf2。

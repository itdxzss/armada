# ADR-0001：拉群任务新 PRD 本期只实现群链接模式

日期：2026-08-02
状态：已接受

## 背景

新 HTML 在“新建拉群任务”中同时提供新群模式、群链接模式和速拉模式。三个模式依赖不同的账号资源、配置合同和执行状态机；若同时展开，会把本次需求从上一版拉群任务调整扩成三条执行链路重建。

## 决定

本期只设计和实现“拉群任务”Tab 下的群链接模式。

- 新群模式不进入页面入口、请求合同、持久化、执行器、统计或验收范围。
- 速拉模式不进入页面入口、请求合同、持久化、执行器、统计或验收范围。
- 群组列表 / 群组管理仍由其他人负责，不因群链接模式依赖群资源而纳入本任务。
- 群链接模式内部的版本范围另行确认，不由本 ADR 猜测。

## 影响

- 需求、接口、表结构和测试只沿群链接链路拆分。
- 前端不展示不可执行的新群和速拉入口，避免占位入口被误认为已支持。
- 后端不为排除模式保留无验证 JSON 字段或空执行分支。
- 已有 `CREATE_NEW` 历史字段和其他业务实现可以继续兼容读取，但不计入本期完成度，也不在本期扩展。

## 被否决方案

同时实现三个模式：会并行引入建群、群链接复用和速拉三套资源及状态语义，无法在当前需求口径下形成单一、可验收的纵切。

# Agent 07：图片素材库

## 目标

验证 `/hyperlink/library` 的素材列表、JPEG 校验、批量串行上传、标签、编辑、删除、引用保护和通用素材选择器。

## 前置与依赖

- 硬前置：Agent 00 公共门禁通过。
- 可与 Agent 04、06 并行；完成后向 Agent 05/01 提供合法素材夹具。
- 方法：字节校验、引用竞态、租户隔离以 API 为主；批量上传、进度、卡片、选择器和错误提示使用浏览器。
- 浏览器操作必须使用腾讯开源的 `browser-skill`，通过 `bsk` 驱动已连接的 Chrome Agent Window，并保存上传进度、失败重试和选择器证据；结束时必须停止本 Agent 的 `bsk` session。
- 素材文件名和素材名使用 `HLQA-{RUN_ID}-A07-` 前缀。
- 每条输出 `Case ID / PASS|FAIL|BLOCKED / Method / Expected / Actual / Evidence / Severity / Cleanup`；只报告问题，不修改业务代码。

## 列表与内容读取

- [ ] ASSET-01【API+浏览器】打开素材菜单，验证默认 pageSize=24、名称 300ms 防抖、标签多选任意匹配、重置和空态。
- [ ] ASSET-02【API+浏览器】验证 12、24、48、96 页容量和稳定分页，列表请求不内联图片 BLOB。
- [ ] ASSET-03【浏览器】核对素材卡的缩略图、名称、ID、最多三个标签、`+N`、尺寸、大小和引用数。
- [ ] ASSET-04【API+浏览器】鉴权读取原图，验证 MIME、字节和 no-cache；不存在、已删除和跨租户素材不可读取。
- [ ] ASSET-05【权限】分别验证 view、upload、edit、delete 权限；选择器有合法消费权限时只能读取可绑定素材。

## 上传与校验

- [ ] ASSET-06【API+浏览器】上传合法 `.jpg/.jpeg`，验证素材名、sizeBytes、width、height、createdBy、时间和缩略图。
- [ ] ASSET-07【API】512000 字节边界允许，超过 500KB 拒绝且不写入 BLOB 或标签关系。
- [ ] ASSET-08【API】拒绝 PNG/GIF/WebP、扩展名伪装、错误 MIME、错误 JPEG magic、损坏 ImageIO 解码和空文件。
- [ ] ASSET-09【浏览器】批量选择最多 100 张；超出只保留前 100 张并提示，任何待上传项非法时整批不开始。
- [ ] ASSET-10【API+浏览器】批量上传严格逐张串行，展示总进度和每文件进度，不得使用并发造成顺序或流量失控。
- [ ] ASSET-11【浏览器】部分失败时成功项完成、失败项保留；重试只处理失败/待传项，成功项不得重复上传。
- [ ] ASSET-12【浏览器】上传中禁止遮罩、ESC 和关闭按钮关闭；timeout/network/canceled/5xx 显示可区分错误。
- [ ] ASSET-13【API+浏览器】公共标签应用到本批每张图片，上传完成后列表和标签候选同步刷新。

## 标签、编辑和删除

- [ ] ASSET-14【API】标签 trim、空值去除、精确去重、最多 20 个、每个最多 64 字；非法 JSON 和尾随内容拒绝。
- [ ] ASSET-15【API+浏览器】验证标签大小写敏感合同，`Tag` 与 `tag` 的筛选和去重结果一致可解释。
- [ ] ASSET-16【API+浏览器】编辑素材名称和标签；名称 trim 后必填且不超过 128 字，保存后列表和候选刷新。
- [ ] ASSET-17【API+浏览器】无引用素材删除确认、取消和成功路径正确；删除后详情和 content 不可读取。
- [ ] ASSET-18【API+浏览器】被旧营销模板、超链模板或超链任务引用的素材删除被阻止，提示真实引用数。
- [ ] ASSET-19【API】模板绑定与素材删除并发时锁定同一素材行，最多一个合法结果，不产生悬空 AssetId。
- [ ] ASSET-20【API】素材按租户共享而非用户私有；同租户不同用户依权限可见，跨租户不可见。

## 通用选择器与兼容回归

- [ ] ASSET-21【浏览器】从模板/任务打开“从素材库选择”，验证名称、标签、pageSize=12、单选、分页和选中高亮。
- [ ] ASSET-22【浏览器】未选择时“使用该素材”禁用；确认后字段显示 48px 缩略图、名称、替换和移除能力。
- [ ] ASSET-23【浏览器】选择器内上传成功后刷新，若新素材出现在当前页则自动选中；失败项可重试。
- [ ] ASSET-24【浏览器】只读字段可显示素材但不能更换或移除；快速切换素材时旧图片响应不覆盖新选择。
- [ ] ASSET-25【API+浏览器】素材库改造不破坏旧群营销模板图片读取、超链模板回显和任务发送前 AssetId 解码。

## 交付与清理

- 为 Agent 05/01/09 输出：合法 JPEG、无引用素材、模板引用素材、任务引用素材的别名和 ID。
- 删除无引用的临时素材；被移交或有引用的素材由 Agent 09 最终清理。
- 不在证据中保存或分享图片数据库内部路径和原始敏感内容。

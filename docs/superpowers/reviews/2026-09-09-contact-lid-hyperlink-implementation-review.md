# 通讯录 LID 实现自审

依据仓库 expert-reviewer 技能检查本次跨仓 diff、调用方及本地测试。此记录不是独立第三方评审，也不代表线上验证。

已修正：

- LID-only 被手机号必填规则丢弃，以及 LID 数字被转换成手机号。
- 快照旧水位覆盖、非所属租户账号写入，以及使用 PARTIAL/SYNCING 快照展开任务。
- Armada 根据间隔分批投递导致实际发送时刻偏离；现在立即入队，协议按实际写出时间控制。
- ACK 计时早于限速等待而提前超时；现在在实际写出前登记 ACK 等待。
- LID 主设备 Agent 标记不同导致被误判为没有主设备密钥；按域、用户及 device=0 判断。
- 未知结果被自动重试、重复/乱序回执重复计数；现在 UNKNOWN 终态不重发，迟到回执可澄清。
- 修改公共联系人查询口径会影响其他业务；保留原 selectNamedByAccount，通讯录任务单独使用 selectSendableByAccount。
- Flyway 新列缺幂等守卫；已补 information_schema 检查，先建立 JID 唯一键再移除旧号码唯一键。

本地验证：后端 220 个相关测试通过，包括真实 Mapper/租户插件/事务的 H2 测试。前端 42 个相关测试、类型检查、定向 lint、构建通过。协议 vet/build、受影响包测试及 race 检查通过。协议全量测试剩余 7 个部署脚本失败和 Noise 8 个向量失败均在未改动的 155fc10 基线复现。

待完成：交接云端探针源码缺失，未能证明当前 app-state 采集覆盖其同一批云端联系人；真实账号采集和链接卡片送达尚未联调。暂不据此建议直接部署。没有连接共享数据库；全量数据模型生成缺少原始结构导出文件，已按 V181 补充增量文档。

# 运行中单条失败跳过（2026-09-11）

## 用户确认与行为

用户明确要求：任务开始后检查失败或单条发送失败，不暂停群；当前条记失败并跳过，继续下一条。

- 启动和全任务第一条实际提交前，仍检查全部目标；检查失败保持零提交。
- 开始发送后，仅检查当前消息使用的原账号、在群/发言资格和当前消息能力。其他角色异常及启动分组人数门槛不阻塞当前合格账号。
- 当前条检查或准备失败，不进入发送队列；保存 `FAILED` 和具体原因，按下一项配置的间隔推进，不暂停群或任务，也不批量跳过某账号的后续项。
- 发送失败回执继续沿用原记录；不重发失败项，不重复推进游标。未知结果仍不自动重发。
- 手动暂停保留。已开始任务/群手动继续时恢复原绑定、原命令和进度，由逐条检查处理后续异常；尚无发送记录的任务仍需全量检查。
- 旧版本已暂停的群不自动恢复，用户手动点击继续后进入新规则。

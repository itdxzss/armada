# Agent 01：超链任务列表与编辑器

## 目标

验证 `/hyperlink/tasks` 的列表、筛选、指标、导出，以及新建、编辑、查看、复制四种编辑器模式。

## 前置与依赖

- 硬前置：Agent 00 公共门禁通过。
- 软前置：需要合法数据包、模板、策略和素材；可消费 Agent 04/05/06/07 的夹具，也可用 `HLQA-{RUN_ID}-A01-` 前缀自行创建。
- 方法：主流程必须 API+浏览器；非法参数和并发冲突主要使用 API。
- 浏览器操作必须使用腾讯开源的 `browser-skill`，通过 `bsk` 驱动已连接的 Chrome Agent Window，并保存关键截图和 Network 摘要；结束时必须停止本 Agent 的 `bsk` session。
- 本 Agent 不执行真实 WhatsApp 发送；创建启用任务时只验证准备回执，不等待真实派发。
- 每条输出 `Case ID / PASS|FAIL|BLOCKED / Method / Expected / Actual / Evidence / Severity / Cleanup`；只报告问题，不修改业务代码。

## 列表用例

- [ ] TASK-01【API+浏览器】打开任务菜单，验证任务列表和 `create-context` 同时加载，页面无白屏和控制台异常。
- [ ] TASK-02【浏览器】核对普通/超级计价模式、余额、参考价、协议数量和说明与 `create-context` 响应一致。
- [ ] TASK-03【浏览器】让 `create-context` 失败但列表成功，验证列表仍可用且价格区域显示失败和重试，不显示假价格。
- [ ] TASK-04【API+浏览器】分别验证任务名称、五种运行状态、三种任务模式、国家和创建时间筛选。
- [ ] TASK-05【API+浏览器】验证组合筛选、Enter 查询、重置和查询后回到第 1 页。
- [ ] TASK-06【API+浏览器】验证 10、20、50、100、200 页容量及 createdAt DESC、id DESC 稳定分页，无重复漏行。
- [ ] TASK-07【浏览器】核对当前页任务、发送、单钩、双钩、点击、封号等指标卡与当前页表格一致。
- [ ] TASK-08【浏览器】验证短链关闭或成功数为 0 时点击指标显示规则正确，不出现 NaN/Infinity。
- [ ] TASK-09【浏览器】验证列设置、隐藏、恢复默认、横向滚动和刷新后的用户级持久化。
- [ ] TASK-10【API+浏览器】验证 runStatus 文案、颜色、`enabled=false` 展示优先级和各状态操作按钮矩阵。
- [ ] TASK-11【权限】验证 create、edit、action、export、attribution_sensitive 权限分别控制对应按钮，后端同时拒绝越权调用。
- [ ] TASK-12【API+浏览器】按当前筛选导出 CSV，验证忽略分页、中文与 BOM 正常、字段和页面/API 数据一致。
- [ ] TASK-13【异常】导出接口返回 JSON 错误或空数据时，不得下载伪 CSV；空数据成功导出只含表头。

## 编辑器用例

- [ ] TASK-14【浏览器】分别打开新建、编辑、查看、复制四种模式，核对标题、可编辑性、按钮和详情回填。
- [ ] TASK-15【API+浏览器】创建单图文任务，验证标题、正文、链接描述、推广链接、预览图和实时预览。
- [ ] TASK-16【API+浏览器】创建普通按钮任务，验证底部小字、唯一 CTA、按钮文字、URL 和短链开关。
- [ ] TASK-17【API+浏览器】创建卡片按钮任务，验证主图、卡片正文、底部小字、唯一 CTA 和实时预览。
- [ ] TASK-18【API+浏览器】新建或复制双图文必须拒绝；历史双图文仅兼容查看，不得错误转换消息类型。
- [ ] TASK-19【API】验证任务名 128、标题 1024、链接描述 512、正文 2000/200、卡片正文 500、按钮文字 30、URL 2048 等边界。
- [ ] TASK-20【API】拒绝 `javascript:`、协议相对 URL、含用户名密码 URL、控制字符、非法 host 和非 HTTP/HTTPS URL。
- [ ] TASK-21【浏览器】引用营销模板，只覆盖消息类型、消息内容、图片、按钮和短链配置，不覆盖任务名、策略、数据包和启动方式。
- [ ] TASK-22【浏览器】引用超链策略，只覆盖任务模式、账号筛选、三个账号上限和周期间隔，不覆盖消息、数据包、间隔和启动方式。
- [ ] TASK-23【API+浏览器】选择、替换、清除和上传素材，最终请求只保存稳定 AssetId；不存在、删除或跨租户素材必须拒绝。
- [ ] TASK-24【API+浏览器】逐项验证国家包含/排除、大洲、分组、渠道、协议、在线、轮号、账号类型、平台、wid/importMode、拉群权限和手机号筛选。
- [ ] TASK-25【API+浏览器】逐项验证号源、好友数、联系人数量、存活天数、注册天数和入库时间范围。
- [ ] TASK-26【API】国家包含/排除重叠、区间上下限颠倒、非法正整数、未知 filter schema 或未知字段必须失败关闭。
- [ ] TASK-27【浏览器】快速修改账号筛选，验证 250ms 防抖、取消旧试算和最终匹配账号/协议/并发上限来自最后条件。
- [ ] TASK-28【浏览器】账号试算失败时显示错误和重试，不能把错误冒充为匹配 0；真实匹配 0 时按设计警告。
- [ ] TASK-29【API+浏览器】验证即时、预发布、周期三种模式的条件字段、默认值和保存结果。
- [ ] TASK-30【API】验证消息间隔 0～10 秒、最多一位小数、最小值不大于最大值。
- [ ] TASK-31【API】验证最大执行账号 0～100、最大使用账号、单号发送上限和三者约束；0 保持 AUTO 语义。
- [ ] TASK-32【API+浏览器】启用任务必须选择可用数据包；停用草稿允许为空；空包、失效包和跨租户包必须拒绝或要求替换。
- [ ] TASK-33【API+浏览器】创建 `enabled=false` 草稿，核对状态、version 和列表展示，不产生运行事实。
- [ ] TASK-34【API+浏览器】复制已完成任务，核对副本名称、sourceTaskId、version、quote/dataPackage 清理以及不复制运行事实。
- [ ] TASK-35【API+浏览器】编辑未开始任务并验证 version 递增；两会话用旧 version 修改时返回冲突且页面保留表单。
- [ ] TASK-36【API+浏览器】已开始或已有 command 的任务不可编辑；查看模式可直接关闭，编辑模式关闭有未保存确认。
- [ ] TASK-37【浏览器】连续点击提交时按钮锁定，只创建或更新一次；失败保留表单，成功刷新列表。

## 交付与清理

- 输出可供 Agent 02 消费的任务别名：一个草稿、一个等待启动任务；只传别名和 ID，不传敏感内容。
- 删除可删除的草稿；需交给 Agent 02 的任务注明所有权和预期清理人。
- 不将“接口返回 200”单独作为 PASS，必须核对页面和重新读取后的事实。

## 2. 必须知道的结论

1. **两个时间都不是号的真实年龄**：Android `creation` = 号在这台设备上激活的时间（号商重新激活就刷新）；商家资料 `member_since` = 成为商家号的时间。个人号目前查不到最初注册时间。perf2 上老号这两列为空，回填要写库，先问用户。
2. **接收号 A（个人号 2449…12）不能再当接收号**：它曾是 perf2 的 zhuan 账号，服务器发给新联系人的还是旧公钥，陌生人发的消息 A 主手机都解不开（"正在等待此消息"）。以后接收号必须**从没在我们任何协议（zhuan / Web / WB）上登录过**。
3. **zhuan 陌生人发 "hi" 5 秒被封**（503 → 重连 403）；单聊不带举报令牌（代码有，调用被注释）。
4. **Baileys（Web 协议）举报令牌缺陷**：算令牌时用了带随机填充的字节，约 75% 消息不带、13% 带错。去掉填充即可。
5. 测试号被另一个平台抢登是用户有意的，在线就能发，**不用纠结**。
6. 做实验必须保留基线：改动走"默认关闭开关 + 白名单"，先记原样再改，不冲掉线上。

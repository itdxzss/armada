# Armada 测试环境账号清理设计

## 目标

将现有 `docs/ops/cleanup-test-accounts.sql` 改为可直接在 Armada 测试库执行的简洁重置脚本，清空所有租户的账号及依赖这些账号的任务数据。

## 清理范围

- 释放账号绑定的 IP 代理，将代理恢复为空闲状态。
- 清空账号、状态、凭据、导入记录、上线日志、群基线和群成员关系。
- 清空进群任务、普通营销任务、建群营销任务及账号占用关系。
- 清空协议命令队列，避免旧账号或旧任务命令继续执行。
- 保留租户、账号分组、IP 代理、群链接、国家数据和营销模板等配置。

## 实现方式

脚本先更新 `ip_proxy` 释放绑定，再用 `TRUNCATE TABLE` 清空目标表并重置自增 ID。执行期间临时关闭外键检查，结束后恢复。

这是测试环境硬清理脚本，不添加预览、环境校验、确认口令、统计输出或事务包装。`TRUNCATE TABLE` 会隐式提交且不可回滚。

## 验收

- SQL 保持简短，可一次性执行。
- 账号和上述任务表为空。
- 原账号绑定的 IP 不再保留 `bound_account_id`，状态为空闲。
- 配置类表不受影响。

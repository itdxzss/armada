# 变更记录：渠道落地页运行时配置

- 日期：2026-07-22
- 影响模块：渠道创建、编辑回显、编辑保存、公开落地页运行时查询

## 变更概述

- `promotion_channel` 新增 `theme_color` 与 `is_app_download_shown`，同一份渠道配置由管理端写入、落地页读取。
- 新增 `GET /api/public/promotion-channels/runtime/{channelCode}`，结合 `X-Forwarded-Host` 校验推广码和访问域名。
- 接口只返回模板编码、主题色、应用下载开关、目标国家和预选区号国家，不返回渠道归属或广告追踪凭据。

## 数据库变更

- Flyway：`V066__promotion_channel_runtime_config.sql`。
- 存量渠道主题色回填为 `#e11d48`，底部应用下载默认展示。
- 不新增索引：运行时 SQL 从域名唯一索引进入，并复用渠道域名有效索引及主键关联。

## 关键约束

- 主题色只接受 `#` 加六位十六进制字符，保存时统一转小写。
- 创建请求未传新字段时使用兼容默认值；编辑请求未传时保留数据库原值。
- 公共请求没有租户上下文，专用只读 Mapper 显式校验租户启用，并校验渠道、域名、模板 `tenant_id` 一致。
- 只返回启用且未软删的渠道、域名和模板；失败响应不区分具体缺失项，避免泄露渠道存在性。
- Nginx 必须使用 `$host` 覆盖 `X-Forwarded-Host`，后端容器只在 Compose 内网暴露，禁止客户端伪造访问域名绕过绑定校验。

## 回滚

- 先确认落地页不再读取新字段，再执行 `rollback.sql` 删除两列并下线公开接口。

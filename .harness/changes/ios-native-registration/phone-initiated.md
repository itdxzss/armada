# 手机主动发起单号注册

## 用户口径
手机点击开始、确认价格后主动向服务端发指令；服务端自动准备许可、取号与收码，手机完成原生注册。控端页面不是前置步骤。默认美国187、0.88美元，自动分配商家，数量1；不扩展注册后的动作。

## 变更
- 新增设备认证入口 `POST /api/device-registrations/begin`，只接收 requestId、countryId、unitPrice；身份/租户仍来自设备认证链。
- 请求ID在手机Keychain保存后才发请求；网络重试保持该ID。服务端设备行锁与现有采购锁共用，当前在途、结果不明、已分配及成功订单只能接续，不新购。
- 仅无号码和无订单的失败/取消任务可以在手机明确发起新请求时替换。历史请求重放接续最新任务；不能借用其他设备请求ID。
- 旧许可过期不再要求用户去页面更新；未开始的同一请求可续期，已开始任务保持原约束。旧控端许可链落后于手机历史时以设备最新任务为准。
- 手机端移除商家选择和读取控端许可的开始路径，改为本机确认价格，再直接调用begin。自动分配请求沿用minPrice=maxPrice和5秒/50次。
- 无表、列、SQL或Redis结构变更。保留控端人工管理接口供现有控端调用，手机不再依赖它们。

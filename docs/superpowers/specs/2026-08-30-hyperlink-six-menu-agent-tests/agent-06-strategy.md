# Agent 06：超链策略

## 目标

验证 `/hyperlink/strategy` 的策略模板 CRUD、三种任务模式、账号筛选、实时试算、启停、乐观锁和任务独占快照。

## 前置与依赖

- 硬前置：Agent 00 公共门禁通过。
- 可与 Agent 04、07 并行执行。
- 方法：业务约束、filter fail-closed、乐观锁和快照使用 API；列表、筛选、抽屉、账号筛选器和提示使用浏览器。
- 浏览器操作必须使用腾讯开源的 `browser-skill`，通过 `bsk` 驱动已连接的 Chrome Agent Window，并保存筛选试算和启停证据；结束时必须停止本 Agent 的 `bsk` session。
- 策略名称统一使用 `HLQA-{RUN_ID}-A06-` 前缀。
- 每条输出 `Case ID / PASS|FAIL|BLOCKED / Method / Expected / Actual / Evidence / Severity / Cleanup`；只报告问题，不修改业务代码。

## 列表、权限与创建

- [ ] STR-01【API+浏览器】打开策略菜单，验证默认 pageSize=20、名称/模式/启停筛选、分页、空态和错误重试。
- [ ] STR-02【API+浏览器】分别验证 view、create、edit、delete 权限，直接调用接口同时受限。
- [ ] STR-03【API+浏览器】创建即时策略，核对名称、任务模式、账号范围、AUTO/固定并发、最大使用账号、单号上限和启用状态。
- [ ] STR-04【API+浏览器】分别创建即时、预发布、周期策略，列表文案、周期字段和账号范围标签正确。
- [ ] STR-05【API】同一租户有效策略名称唯一；删除后允许复用；不同租户允许同名。

## 执行限制与模式

- [ ] STR-06【API+浏览器】最大执行账号只能为 0～100 的整数，0 必须持久化为 AUTO，不得改写为固定 1。
- [ ] STR-07【API】最大使用账号和单账号最大发送数必须为非负整数。
- [ ] STR-08【API】固定并发非零且最大使用账号非零时，最大执行账号不得大于最大使用账号。
- [ ] STR-09【API+浏览器】周期模式每轮最大账号至少 1，周期间隔至少 30 分钟；非周期保存时周期间隔归一为 0。
- [ ] STR-10【浏览器】切换到周期模式时合理补全默认周期间隔和账号数；切回非周期不残留错误必填状态。

## 账号范围与试算

- [ ] STR-11【API+浏览器】逐项验证国家包含/排除、大洲、分组、渠道、协议、在线、轮号、账号类型、平台和号码等筛选。
- [ ] STR-12【API+浏览器】逐项验证号源、好友数、联系人数量、存活天数、注册天数、入库时间和允许拉群等画像筛选。
- [ ] STR-13【API】包含/排除相同国家、非法范围、非法枚举、未知 schema 和损坏 JSON 必须失败关闭。
- [ ] STR-14【API】画像值为 NULL 时，配置了对应筛选条件的账号不得被当成 0/false 命中。
- [ ] STR-15【API+浏览器】account-context 返回分组、国家、渠道、协议候选；失败时页面显示重试，不凭名称猜默认组 ID。
- [ ] STR-16【API】defaultAccountGroupIds 只允许来自稳定 `public + hyperlink` 业务编码；无法证明时返回空而非放宽范围。
- [ ] STR-17【浏览器】快速修改筛选，验证 250ms 防抖、取消旧请求、最终试算结果来自最后条件。
- [ ] STR-18【API+浏览器】真实匹配 0 允许保存但显示警告；试算错误必须显示错误，不能冒充 0。
- [ ] STR-19【API】account-match-count 请求体必须为 raw filter；包装对象、未知字段和非法值返回稳定 400。

## 启停、更新、删除与任务快照

- [ ] STR-20【API+浏览器】停用后策略不出现在任务 options；重新启用后恢复，列表状态同步。
- [ ] STR-21【API+浏览器】完整更新携带 version 并原子递增；旧 version 返回冲突，页面刷新真实状态。
- [ ] STR-22【API+浏览器】删除后列表、详情和 options 不可见，名称允许复用。
- [ ] STR-23【API】策略列表、详情和 options 只能返回 TEMPLATE，任务的 TASK_SNAPSHOT 不得通过猜 ID 暴露。
- [ ] STR-24【API+浏览器】任务选择策略后保存独占快照；模板策略后续修改、停用或删除不影响已有任务。
- [ ] STR-25【API】任务最终手工调整过策略字段时，任务快照保存最终表单值，同时 sourceStrategyId 只用于来源追溯。
- [ ] STR-26【API】任务报价、列表、详情和运行必须读取同一任务快照，不得重新读取当前模板策略。

## 交付与清理

- 为 Agent 01/09 输出即时、预发布、周期三个启用策略别名和 ID。
- 不删除已移交策略；其余策略软删除并验证名称复用。
- 任务快照属于任务，不应由本 Agent 直接删除或修改。

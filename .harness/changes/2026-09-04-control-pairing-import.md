# 变更记录：控台固定认证码导号

- 日期 / 分支：2026-09-04 / `1.0.3-snapshot`
- 需求来源：主设备在异地，由持有人输入认证码，将账号登录到 Armada 控台
- 状态：本地开发与聚焦回归完成，待联调和真实主设备验收

## 目标

在账号导入权限内新增短时认证码会话。控台流程固定请求 `88888888`；公开推广配对继续使用随机码。

## 范围

- In scope：认证接口、租户隔离、目标分组校验、手机号活动会话唯一锁、代理预留、协议事件关联、凭据和在线账号落库。
- Out of scope：Android 原生协议认证码、测试环境部署、真实 WhatsApp 主设备验收、历史导入批次生成。

## 关键设计决策

- 复用已有配对会话和 Kafka 完成事件，新增场景字段区分推广与控台，不复制第二套协议状态机。
- 固定码只由认证后端写入协议请求，浏览器没有自定义配对码字段。
- 控台状态查询必须同时命中 `session_id + tenant_id`；接口要求 `tenant:account:edit`。
- 推广和控台继续共用 `active_phone` 唯一键，禁止同一号码并发配对。
- 协议层回传码不是 `88888888` 时失败关闭，不写账号凭据。
- 成功账号按普通自购 Web 账号进入所选分组，不产生推广渠道归因或 CAPI 事件。

## 数据库 / API

- Flyway `V179`：新增 `pairing_scene`、`account_group_id`、`remark`，推广渠道列改为可空。
- 新增 `POST /api/account-pairing-sessions`。
- 新增 `GET /api/account-pairing-sessions/{sessionId}`。

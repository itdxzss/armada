# ADR-0004：第一阶段只使用自定义粘贴群链接

日期：2026-08-02
状态：已接受

## 背景

普通群链接版原型同时提供“群组列表分组”和“自定义粘贴链接”两个群入口。群组列表和群组分组由其他人负责；若第一阶段依赖其管理页面或新合同，会阻塞已确认的最小真实执行链路。

## 决定

第一阶段只支持自定义批量粘贴群链接。

- 不展示“群组列表分组”选择器。
- 不在本任务内实现群组分组的新增、编辑、删除或查询合同。
- 粘贴链接必须执行格式归一、租户内去重、识别、健康/JID 校验，并复用或写入统一 `group_link` 事实。
- 后续阶段在群组管理 API 和数据口径稳定后，再增加按群组列表分组选择链接的入口。

## 影响

- 第一阶段没有群组管理跨团队前置依赖，可以独立跑通创建和执行。
- 任务执行明细引用 `group_link.id` 和群 JID，不把原始粘贴文本当作长期业务主键。
- 同一批次内重复链接、租户内已有链接和无效链接必须逐条返回真实处理结果。
- 后续接入分组选择时应复用同一链接归一、去重和执行合同，不能另建一套群事实。

## 被否决方案

第一阶段同时依赖群组列表分组：会把其他团队的数据和接口交付变成本阶段阻塞项，不利于先验收最小真实链路。

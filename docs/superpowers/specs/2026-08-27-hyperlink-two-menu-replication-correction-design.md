# 超链两个菜单完整复刻纠偏设计

- 日期：2026-08-27
- 来源：用户在第一套环境验收时指出“列字段不一致、按钮功能未全部实现”
- 竞品事实源：`../hylbuiaxykfrontendsource/readable/assets/data-CdPwdTG4.js`、`templates-BLWMxusB.js`、`hyperlink-button-editor-CcRhevR2.js`
- 目标仓库：`armada` + `wheel-saas-pure-web`

## 1. 结论

第一套环境部署的是一期资源子集，不是最初约定的完整复刻。纠偏后以竞品当前构建产物为页面事实源，
不再沿用“一期主动隐藏入口、把组合指标拆成普通列”的缩减口径；模板按钮仍按竞品锁定为单个 URL。

## 2. 逐页对账

### 2.1 数据包

| 区域 | 竞品事实 | 当前偏差 | 纠偏 |
|---|---|---|---|
| 筛选 | 名称、创建时间、UV 占比、主要国家 | 使用名称、创建日期、普通国家多选 | 对齐竞品字段、文案和查询参数；主要国家按当前代号码量计算 |
| 表格 | 选择、ID、数据包、号码使用、投递漏斗、创建时间、操作 | 11 个平铺统计列 | 改为 6 个业务组合列 |
| 数据包列 | 图标、名称、主要国家、备注；名称进入访问趋势 | 只有名称 | 补齐组合展示和趋势入口 |
| 行操作 | 导入、导出、重置失败、更多 | 查看、追加导入、覆盖导入、编辑、删除 | 对齐入口；导入模式放回导入弹窗 |
| 更多 | 查看号码、重命名、删除数据包 | 直接平铺 | 对齐下拉菜单 |
| 顶部操作 | 新建、批量导出号码、批量导出点击记录、超链点击分析 | 只有新建 | 补齐入口；号码导出接真实 API，点击功能展示真实空态 |
| 号码抽屉 | `#`、手机号、入库时间 | 额外展示内部代次、池状态、批次、国家 | 默认列对齐竞品；筛选和服务端分页保留 |

数据包导出支持 `all/unused/success/single/double/failed/fail_404`。失败重置只把
`RETRYABLE_FAILED` 改回 `UNUSED`，`UNREGISTERED` 不重置。导出是敏感号码读取，新增独立
`tenant:hyperlink_data:export` 权限；迁移只创建权限节点，不自动给普通角色授权，部署后由管理员按角色显式配置。

主要国家取当前代号码量最多的国家；并列时优先已识别国家，再按 ISO2 稳定排序，空包不归入
`UNKNOWN`。马来西亚、新加坡、中国、香港、澳门、台湾属于禁导国家/地区，导入文件只要包含其中
任一号码，后端就整批拒绝并记录失败审计，不写入任何号码行；前端对已有禁导国家的数据包同步禁用导入入口。

访问趋势、点击记录和点击分析必须读取真实点击/发送事实。当前尚无超链任务执行表，因此本轮先交付完整
入口和真实空态，不提前增加死列、不提供假下载；任务执行模块落地时按已冻结接口写入事实表并实现下述接口。

### 2.2 超链模板

| 区域 | 竞品事实 | 当前偏差 | 纠偏 |
|---|---|---|---|
| 筛选 | 模板名称、消息类型 | 额外增加创建时间 | 去掉创建时间筛选 |
| 表格 | 模板名称/类型、更新时间、操作 | 拆出 ID、名称、类型、标题、引用、版本 | 合并为竞品 3 列 |
| 操作 | 编辑、复制、删除 | 额外查看按钮 | 编辑器本身含实时预览，移除独立查看 |
| 编辑器 | 模板页把通用按钮编辑器锁成 1 个 URL 按钮，并隐藏新增/删除 | 同为单个 URL 按钮 | 保持契约，只对齐文案、字段顺序和视觉结构 |
| 跳转参数 | 页面提示“任务时配置”，但构建代码仍保留按钮 URL 字段 | Armada 保存 URL target | 保持稳定字段，任务阶段复制快照 |

竞品虽然复用了支持 URL、电话、复制、快捷回复的通用编辑器，但模板页调用参数明确为
`max: 1`、`locked-type: cta_url`、`hide-add-button`。因此本次不扩按钮枚举，避免把通用组件能力误判成
这个菜单已经开放的产品能力。

## 3. API 与数据影响

### 3.1 数据包本轮新增

- `POST /api/data-packages/{id}/reset-failed`
- `GET /api/data-packages/{id}/export?usageStatus=...`
- `POST /api/data-packages/export`

点击事实模块落地后再新增：

- `GET /api/data-packages/{id}/visit-trend`
- `POST /api/data-packages/{id}/visit-trend/export`
- `POST /api/data-packages/clicks/export`
- `GET /api/hyperlink-click-analysis/never-click`
- `GET /api/hyperlink-click-analysis/uv-ratio`
- 对应两个分析导出端点

列表查询补 `minUvPercent/maxUvPercent`。在点击事实未上线前，点击 UV 真实口径为 0；最小值大于 0 时
返回空页，最大值为 0 或未填写时正常查询，不能把 0 伪装成有点击的数据。

### 3.2 模板契约

- 继续只接受一个 `CTA_URL`，沿用现有 JSON 列和服务端校验，无数据库变更。
- 前端去掉不属于竞品列表的独立查看入口；编辑抽屉继续承担预览与编辑。

## 4. 安全、租户与回滚

- 所有查询和更新继续由租户拦截器注入 `tenant_id`。
- 导出端点必须先校验父包属于当前租户且未删除，不允许凭 ID 穿透。
- CSV/TXT 通过标准下载响应返回，不把完整手机号写入日志。
- 回滚优先隐藏新增入口并回退前后端；按钮 JSON 向后兼容，已有非 URL 类型无需删数据。
- `data_package_stat` 属于数据包当前代汇总聚合；点击事实没有写入方，本轮不向该表增加预留列。

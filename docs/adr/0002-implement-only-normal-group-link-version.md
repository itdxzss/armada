# ADR-0002：群链接模式本期只实现普通群链接版

日期：2026-08-02
状态：已接受

## 背景

新原型在群链接模式下提供“新增历史群组营销版本、普通群链接版本、公告群链接版本”。三个版本虽然复用部分选群和拉人配置，但历史群组营销版增加营销账号、模板、发送、静默和封控状态；公告群链接版也需要单独确认群类型和协议行为。

## 决定

本期只实现普通群链接版。

- 新增历史群组营销版整体延期，包括营销配置、营销执行、营销统计和营销人工操作。
- 公告群链接版整体延期。
- 页面不保留两个延期版本的可选入口，API 不接收相应版本值。
- 普通群链接版归属普通拉群任务业务类型，不进入现有 `GROUP_MARKETING` 状态机、候选历史群等待池或营销聚合统计。
- 普通群链接第一阶段只交付真实拉群核心配置和执行；群资料/权限设置、管理与拉手完成归档进入普通版第二阶段。“创群成功账号移至分组”因普通版不建群而删除。

## 影响

- 第一阶段需求定义普通群链接的链接输入、账号角色、料子、拉人执行、状态和详情；群设置与完成归档按第二阶段独立验收。
- 任务列表、看板和详情中的营销状态、消息发送、营销账号不足等字段对本期不适用，应删除或明确不展示，不能写入零值冒充执行结果。
- 第一阶段任务列表展示任务状态、当前阶段、群链接进度、拉人结果和异常群数；详情只展示管理员、拉手、站台资源及拉人执行事实。导出明细进入第二阶段。
- 后续恢复历史群组营销版或公告群链接版时，应作为新的纵切扩展版本合同，不污染普通群链接执行器。

## 被否决方案

三个群链接版本同时实现：会把普通拉人链路、历史群接管营销链路和公告群语义重新耦合，超出当前确认范围。

# 手机手动输入导入分组

## 需求

V8 测试人员只输入控端预先创建的分组名称，不能查询或查看租户全部分组。控端在令牌租户内查找同名未删除分组：存在则导入，不存在则返回 404 `分组不存在`，V8 原样提示且保持登录。

## 实现边界

- 删除设备专用 `GET /api/device-imports/groups` 控制器、安全链和 nginx 路由。
- 上传请求由 `accountGroupId` 改为必填字符串 `groupName`，去除首尾空白后校验非空且不超过 100 个 Unicode 字符。
- 使用租户拦截下的 `AccountGroupMapper.selectActiveByName()` 查找目标分组，并把得到的 ID 交给现有导入事务；不新建、不模糊匹配、不回退默认组。
- 分组不存在、已删除或属于其他租户均返回 404 `{"message":"分组不存在"}`，导入表不产生记录。
- 手机、后端与专用网关必须按同一契约一起发布；本地通过不代表已经部署或完成真实账号验收。

## 验证计划

- Java 转换器、MVC、Service 和 H2 真实 Mapper/事务测试覆盖名称规范化、跨租户、软删、未知分组和零落库。
- 隔离 nginx/Compose 测试覆盖旧分组列表路径 404、请求体原样转发、方法与安全头。
- V8 单元/UI 测试覆盖不发起列表请求、输入确认、`groupName` 请求体、404 提示、失败不登出和成功交接。

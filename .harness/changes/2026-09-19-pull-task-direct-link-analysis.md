## 关键结论

- 不能只隐藏表单：管理分组仍在前后端必填、启动固定要求管理、首次执行从管理进群起步。
- 建议独立持久化流程标识和拉手准备入口，复用现有拉人/回执/资源能力，保留旧流程默认行为。
- 新模式需由拉手入群结果绑定真实群 ID，并使补号、恢复、换群回到新入口。
- 同时取消两类任务内互加与料子提权，避免隐性进入旧阶段。
- 拉手管理员身份不作为条件，新模式不提权；遇到普通成员加人权限限制或入群审批时记录明确执行结果。
- 上传与匹配仅使用当前页面输入或无任务落库的校验；点击创建后事务内生成正式任务，创建合同不含 draftTaskId，不触碰旧草稿。

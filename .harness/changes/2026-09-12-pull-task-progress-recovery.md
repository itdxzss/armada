## 关键设计决策
- 行锁覆盖同群计划和结果的本地事务；成员查询和协议调用不在本次新增锁内等待。
- 领取拉手前运行计划检查：取消已成功或超过预算的未提交计划，再校正人数；空批无需拉手即推进，且不增加协议发送间隔。
- 历史待执行号码按最新无活动台账恢复为真实 UNKNOWN/FAILED；初始选人不能重新选择已有尝试的号码。
- 修复 MySQL 单表 UPDATE 从左到右赋值导致的空批判断偏移，增加 SQL 结构回归。
- 历史成功保留获胜调用和成功时间，只清匹配的活动指针。取消计划保留尝试历史。
- 收集窗口过期不代表失败。缺失结果保留 UNKNOWN，迟到成功仍可提升。
- 禁止将 UNKNOWN/UNCERTAIN 直接重置待执行。账号补充、换群不在本次范围。

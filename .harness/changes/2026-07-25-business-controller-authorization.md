# 业务接口权限校验补齐

## 目标

- 在现有登录校验基础上，为非公开业务 Controller 补齐与菜单 `perm_key` 对应的 `@PreAuthorize` 校验。
- 防止用户绕过前端菜单，通过 URL、Postman 等方式访问未授权业务接口。
- 保持共享基础查询可被实际依赖它的多个菜单使用，不扩大写操作权限。

## 业务约束

- 不新增 Mock 数据，不改变现有业务处理逻辑。
- 系统管理继续沿用已有的按钮级权限。
- 当前业务菜单多数只有查看权限，因此该菜单下的操作接口统一受对应菜单权限保护。
- “导入链接”和“群组列表”是两个独立菜单，必须使用不同的权限编码。
- 登录、当前用户菜单、国家选项等身份或公共字典接口继续由全局登录校验保护。
- `/api/public/**` 公开推广接口保持公开。

## 共享接口规则

- 账号列表、账号分组列表、营销模板列表等查询接口，允许实际使用它们的菜单权限访问。
- 账号分组、营销模板等写操作只允许其所属管理菜单访问。
- 群链接列表允许“导入链接”“群组列表”“拉群任务”访问；群链接资料和成员操作只允许“群组列表”访问。
- IP 检测单条接口允许 IP 管理和 IP 统计使用，其余 IP 管理操作不扩大权限。

# Agent 05：超链营销模板

## 目标

验证 `/hyperlink/templates` 的三类一期模板、字段矩阵、素材绑定、实时预览、复制、乐观锁和删除。

## 前置与依赖

- 硬前置：Agent 00 公共门禁通过。
- 素材前置：优先消费 Agent 07 的合法 JPEG 素材；也可使用 `HLQA-{RUN_ID}-A05-` 自建专属素材。
- 方法：字段矩阵、非法 payload、版本和租户隔离使用 API；创建、预览、素材选择、复制和删除使用 API+浏览器。
- 浏览器操作必须使用腾讯开源的 `browser-skill`，通过 `bsk` 驱动已连接的 Chrome Agent Window，并保存三类消息预览和 Network 摘要；结束时必须停止本 Agent 的 `bsk` session。
- 模板名称统一以 `HLQA-{RUN_ID}-A05-` 开头。
- 每条输出 `Case ID / PASS|FAIL|BLOCKED / Method / Expected / Actual / Evidence / Severity / Cleanup`；只报告问题，不修改业务代码。

## 列表和权限

- [ ] TPL-01【API+浏览器】打开模板菜单，验证默认分页、名称筛选、消息类型筛选、空态和错误重试。
- [ ] TPL-02【API+浏览器】分别验证 view、create、edit、copy、delete 权限，隐藏按钮不能替代后端鉴权。
- [ ] TPL-03【API】GET options 验证 keyword、messageType、limit=1～100 和当前租户隔离。

## 三类消息模板

- [ ] TPL-04【API+浏览器】创建单图文模板，验证模板名、标题、正文、链接描述、推广链接和链接预览 AssetId。
- [ ] TPL-05【API+浏览器】创建普通按钮模板，验证可选底部小字、恰好一个 CTA、按钮文字、目标 URL 和 useShortLink。
- [ ] TPL-06【API+浏览器】创建卡片按钮模板，验证可选主图、必填卡片正文、底部小字和恰好一个 CTA。
- [ ] TPL-07【API+浏览器】新建双图文或将其他类型改成双图文必须明确拒绝；页面不得提供可提交入口。
- [ ] TPL-08【API】验证 schemaVersion 只允许 1，messageType 只允许 1/2/3/4 且一期写入仅允许 1/3/4。
- [ ] TPL-09【API】验证名称 128、标题 512、单图文正文 2000、按钮正文 200、链接描述 512、卡片正文 500、备注 255 的边界。
- [ ] TPL-10【API】按钮消息必须恰好 1 个 CTA_URL、sort=1、useShortLink 显式 boolean；多按钮、空按钮和未知类型均拒绝。
- [ ] TPL-11【API】推广/按钮 URL 只允许绝对 HTTP(S)，拒绝非法 host、相对路径、用户密码、危险 scheme 和超长值。

## 素材、预览与更新

- [ ] TPL-12【API+浏览器】从素材库搜索、选择、替换、清除图片，并通过鉴权 Blob/Object URL 正确回显。
- [ ] TPL-13【API】不存在、已删除、非 JPEG、超过 500KB、损坏或跨租户 AssetId 绑定必须失败。
- [ ] TPL-14【浏览器】切换消息类型时只清理不再适用的素材；实时预览与当前有效字段一致。
- [ ] TPL-15【浏览器】编辑详情完整回填；关闭抽屉释放旧 Object URL，快速切换模板时旧图片响应不得覆盖新模板。
- [ ] TPL-16【API+浏览器】完整编辑后 version 原子递增；旧 version 更新返回冲突且页面提示刷新。
- [ ] TPL-17【API】同租户有效模板名称唯一，不同租户允许同名；并发同名创建最多一个成功。

## 复制、删除和任务快照

- [ ] TPL-18【API+浏览器】复制模板只复制业务内容，服务端生成唯一递增副本名，新记录 version=1、审计人正确。
- [ ] TPL-19【API】复制前重新锁定并验证素材；源素材删除或跨租户时复制失败且不生成半成品模板。
- [ ] TPL-20【API+浏览器】删除确认、取消和成功路径正确；成功后列表、详情和 options 都不可读取。
- [ ] TPL-21【API】跨租户 ID 的详情、编辑、复制、删除统一不可见，不泄露源模板名称或素材信息。
- [ ] TPL-22【API+浏览器】任务引用模板后再修改或删除模板，已保存任务的消息内容和 AssetId 快照保持不变。

## 交付与清理

- 为 Agent 01/09 输出单图文、普通按钮、卡片按钮三个模板别名和 ID。
- 不删除已明确移交给任务测试的模板；其余模板软删除，并删除本 Agent 创建且无引用的素材。
- 模板删除当前若无任务引用保护，不得把“可删除模板”等同于“任务内容跟着删除”；必须对账任务快照。
